## The entry

> Tip: your AI agent is watching the same spinner as you, wondering if you meant what you typed. Neither of you is wrong. Both of you, breathe.

One loading-screen tip, 141 characters, for stressed developers and the AI coding agents building beside them. The joke lands mid-build: the spinner is the one thing human and agent genuinely share, and the punchline absolves them both — then tells them both to breathe.

## How it works

`main.py` (stdlib only, no network) writes the single-line tip to `/output/entry.txt`, enforcing the competition gate in code: the text must be one line, 1–200 characters, and not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
